# 04 实验协议

## 1. 实验目标

实验必须回答四类问题：

1. **有效性：** 方法是否比强基线更好？
2. **因果性：** 哪个模块造成改善？
3. **泛化性：** 未见轨迹和未见虚拟机床上是否仍有效？
4. **边界性：** 在何种噪声、失配或不可重复扰动下失效？

## 2. 实验设计总览

| 实验编号 | 问题 | 主要对比 | 主要输出 |
|---|---|---|---|
| E0 | 仿真环境是否可信 | 理想回环 vs 虚拟物理机床 | 阶跃、频响、跟踪曲线 |
| E1 | 核心方法是否有效 | 全部基线 vs 完整方法 | 关键误差、全局误差、试次效率 |
| E2 | 自动窗口是否有贡献 | 自动 vs 固定 vs 随机窗口 | 窗口质量、最终误差 |
| E3 | 模型失配下是否安全 | 无门控 vs 信赖域/回退 | 发散率、错误更新率 |
| E4 | 是否跨域泛化 | 已见 vs 未见轨迹/机床 | 泛化性能、适应轮数 |
| E5 | 是否鲁棒 | 噪声、漂移、非重复扰动 | 鲁棒曲线、失败边界 |
| E6 | 成本是否合理 | 各方法 | 每轮时间、内存、QP规模 |

## 3. 轨迹任务集

### 3.1 基础调试集

- 直线：检查单轴动态和坐标变换；
- 圆：检查连续曲率和轴间相位差；
- 圆角矩形：检查拐角和加减速；
- S 形样条：检查曲率变号；
- 八字轨迹：检查方向切换和交叉区域。

### 3.2 主实验轨迹族

建议每类生成多个参数变体：

1. 多段直线—圆弧轮廓；
2. 圆角多边形；
3. 自由 B 样条闭合曲线；
4. 局部高曲率但连续的曲线；
5. 曲率不高、但因轴动态和时延形成误差峰值的轨迹；
6. 不同进给速度下的同一几何路径。

第 5 类非常重要，它用于证明自动窗口不是曲率阈值的同义替换。

### 3.3 数据划分

按轨迹生成机制划分，不仅按样本随机划分：

- Train：用于残差模型或窗口评分器训练；
- Validation：用于确定权重、阈值和信赖域参数；
- Test-ID：未见具体轨迹，但几何生成分布相同；
- Test-OOD-Geometry：未见几何族或更高曲率范围；
- Test-OOD-Speed：未见进给速度范围。

任何测试轨迹都不能用于超参数调节。

## 4. 虚拟机床域

### 4.1 域参数

每个虚拟机床域至少包含：

- X/Y 轴质量或等效惯量；
- PID 增益；
- 阻尼；
- 库仑和 Stribeck 摩擦；
- 时延；
- 力/速度/加速度饱和；
- 轴间耦合；
- 传感器噪声；
- 试次间参数漂移。

### 4.2 初始范围确定

不能直接把任意随机范围写入论文。推荐流程：

1. 先设定无量纲或归一化基准域；
2. 检查所有采样域闭环稳定；
3. 排除误差始终近零的过易域；
4. 排除任何方法都无法恢复的过难域；
5. 在 pilot 阶段确定难度分层；
6. 在正式测试前冻结域范围和种子。

可将难度定义为标准控制器在无学习情况下的关键误差分位数：

- Easy：较低分位；
- Medium：中间分位；
- Hard：较高但仍可恢复分位；
- Out-of-support：超出训练范围的压力测试。

### 4.3 域划分

- Train domains：残差模型训练；
- Validation domains：参数选择；
- Test-ID domains：训练分布内未见实例；
- Test-OOD-Parameter：参数范围外；
- Test-OOD-Structure：增加训练时没有的摩擦、耦合或时延结构。

结构外测试比单纯改变二阶参数更有说服力。

## 5. 对比方法

### B0：No Learning

只执行原始 LinuxCNC/CAM 轨迹。

作用：给出初始误差和问题难度。

### B1：Conventional Offline Trajectory Optimization

仅根据名义模型，在执行前优化一次进给率或样条轨迹，之后不利用试次反馈。

作用：验证重复学习相对于一次性模型优化的价值。

### B2：Standard Axis-wise ILC

以各轴全时域跟踪误差为目标，使用相同的样条维度、试次预算和约束。

### B3：Contour ILC

以全时域轮廓误差为目标，不做关键窗口选择。

### B4：Fixed-Window ILC

根据曲率、加速度或跃度阈值固定选择窗口。

### B5：Segmented ILC

按几何段或跃度变化分段，每段使用固定增益/权重。

### B6：Random-Window Control

使用与自动方法相同的窗口数量和总长度，但随机选择位置。

作用：排除“只要稀疏优化就会变好”的解释。

### P：Proposed Method

自动关键窗口、名义模型局部雅可比、约束 QP、信赖域和回退；残差模型是否纳入完整方法取决于最终创新定义。

## 6. 公平比较原则

所有方法必须共享：

- 相同初始轨迹；
- 相同虚拟机床域和随机种子；
- 相同最大试次数；
- 相同样条自由度或等价更新自由度；
- 相同速度、加速度、跃度约束；
- 相同数据采样频率；
- 相同停止条件；
- 相同的计算预算说明。

如果某基线无法自然使用同一参数化，应报告其变量数量和计算量，不能隐藏。

## 7. 评价指标

### 7.1 主要指标

#### 关键窗口最大绝对误差

\[
E_{\mathrm{critical,max}}
=
\max_{t\in W^\ast}|e_{\mathrm{con}}(t)|
\]

其中 \(W^\ast\) 是独立定义的评价窗口，不能直接使用方法自己选择的窗口作为唯一评价范围。建议由任务定义或离线统一规则生成评价窗口。

#### 关键窗口 RMSE

\[
E_{\mathrm{critical,rmse}}
=
\sqrt{
\frac{1}{|W^\ast|}
\sum_{t\in W^\ast}e_{\mathrm{con}}(t)^2
}
\]

#### 学习曲线面积

\[
\operatorname{AUC}
=
\sum_{k=0}^{K_{\max}}
\frac{E_k}{E_0+\epsilon}
\]

AUC 同时反映最终性能和试次效率，推荐作为主要终点之一。

### 7.2 次要指标

- 全局轮廓 RMSE；
- 全局最大误差；
- 轴跟踪 RMSE；
- 周期时间；
- 达到目标阈值的试次数；
- 更新接受率；
- 回退次数；
- QP 不可行率；
- 速度/加速度/跃度约束违反量；
- 每轮计算时间；
- 最终命令平滑度。

### 7.3 窗口检测指标

窗口不存在唯一人工真值时，不宜只使用分类准确率。可评价：

- 窗口总覆盖率；
- 窗口稀疏率；
- 所选窗口内误差峰值覆盖率；
- 窗口屏蔽后的性能下降；
- 在相同窗口预算下的任务改善；
- 跨试次窗口稳定性；
- 与曲率/跃度窗口的重叠和差异。

## 8. 主实验 E1

### 8.1 目的

验证完整方法在试次效率、关键误差和安全性方面是否优于强基线。

### 8.2 协议

对每个测试轨迹—机床域组合：

1. 使用相同初始轨迹运行所有方法；
2. 每种方法最多运行 \(K_{\max}\) 轮；
3. 保存所有候选试次，不只保存最终轮；
4. 选择最佳已接受试次作为最终输出；
5. 对存在噪声的域使用多个噪声种子；
6. 记录失败、不可行和超时，不得删除失败样本。

### 8.3 结果形式

- 主表：每种方法的关键最大误差、关键 RMSE、全局 RMSE、AUC、约束违反率；
- 主图：归一化关键误差随试次变化；
- 配对散点图：每个测试域中 Proposed 对最强基线；
- 轨迹图：代表性成功和失败案例。

## 9. 自动窗口实验 E2

比较：

- 自动窗口；
- 曲率窗口；
- 跃度窗口；
- 当前误差峰值窗口；
- 随机窗口；
- 全轨迹。

控制变量：

- 相同窗口数量；
- 相同窗口总长度；
- 相同 QP 和信赖域；
- 相同样条参数数量。

需要证明两件事：

1. 自动窗口与简单几何规则并不等价；
2. 性能增益来自窗口位置，而不是减少目标采样点本身。

## 10. 模型失配实验 E3

### 10.1 参数失配

改变：

- 固有频率；
- 阻尼；
- 静态增益；
- 时延；
- 摩擦强度。

### 10.2 结构失配

学习器始终使用线性二阶模型，但 plant 增加：

- 饱和；
- 死区；
- Stribeck 摩擦；
- 轴间耦合；
- 可变时延。

### 10.3 对比

- 精确模型上界；
- 固定名义模型；
- 名义模型＋固定小步长；
- 名义模型＋信赖域；
- 名义模型＋残差不确定度＋信赖域；
- 无回退版本。

主要结果：

- 实际恶化更新比例；
- 发散率；
- 回退率；
- 达到目标的试次数；
- 性能—安全折中。

## 11. 泛化和迁移实验 E4

### 11.1 未见轨迹

将已学习的窗口评分器和残差模型冻结，测试：

- 新的控制点组合；
- 新的曲率分布；
- 新的路径长度；
- 新的进给速度。

### 11.2 未见机床

对每个测试域比较：

- 从零开始；
- 使用训练域平均初始化；
- 使用最近域初始化；
- 使用学习的跨域初始化。

评价：

- 前 1-3 轮误差；
- 达到阈值的试次数；
- 最终性能；
- 负迁移比例。

若不做元学习，仍可将“已学习残差模型是否减少试次数”作为较轻量的迁移实验。

## 12. 鲁棒性实验 E5

### 12.1 可重复误差

ILC 应能学习：

- 固定时延；
- 固定摩擦；
- 固定轴带宽差；
- 固定周期扰动。

### 12.2 不可重复误差

压力测试：

- 每轮独立白噪声；
- 随机负载变化；
- 随机时延抖动；
- 初始位置偏差；
- 参数缓慢漂移。

预期边界：

ILC 对可重复误差更有效；当不可重复扰动占主导时，学习效果应下降。论文应报告这一边界，而不是试图掩盖。

## 13. 消融实验

核心消融表：

| 版本 | 自动窗口 | 全局保护项 | 信赖域 | 回退 | 残差不确定度 |
|---|---:|---:|---:|---:|---:|
| A0 | 否 | 是 | 是 | 是 | 否 |
| A1 | 是 | 否 | 是 | 是 | 否 |
| A2 | 是 | 是 | 否 | 否 | 否 |
| A3 | 是 | 是 | 是 | 是 | 否 |
| Full | 是 | 是 | 是 | 是 | 是 |

额外敏感性：

- 窗口数量 \(K\)；
- 窗口半宽；
- 窗口总长度比例；
- 样条控制点数量；
- QP 正则权重；
- 信赖域初值；
- 雅可比有限差分步长；
- 残差模型训练样本量。

## 14. 统计方案

### 14.1 实验单位

实验单位是“轨迹—虚拟机床域—噪声种子”组合。由于不同方法运行在相同组合上，应使用配对比较。

### 14.2 建议报告

- 均值和标准差；
- 中位数和四分位距；
- 95% bootstrap 置信区间；
- 每个组合的配对散点；
- 成功率和失败率。

### 14.3 显著性检验

根据分布和样本量选择：

- 近似正态的配对差值：paired t-test；
- 非正态或重尾：Wilcoxon signed-rank test；
- 多方法比较：Friedman test 加事后配对；
- 多重比较：Holm 校正。

统计显著不能替代实际效果量。必须同时报告：

- 绝对改变量；
- 相对改变量；
- 效果量；
- 置信区间。

### 14.4 样本规模

正式规模应由 pilot 中的跨域方差和目标效果量决定。若暂时无法做功效分析，可先以至少数十个独立轨迹—域组合做算法比较，并在论文中报告确切数量。不要把同一轨迹的时间采样点错误地当成独立样本。

## 15. 预注册和防止调参污染

在正式测试前冻结：

- 主要指标；
- 方法版本；
- 训练/验证/测试域；
- 随机种子列表；
- 试次预算；
- 停止条件；
- 超参数；
- 失败判定；
- 异常数据处理规则。

测试后若修改算法，应生成新的版本号并重新运行全部方法，不能只重新运行 Proposed。

## 16. 论文结果最低证据链

一篇完整小论文至少需要：

1. 环境验证图；
2. 主方法对强基线的量化表；
3. 关键窗口可视化；
4. 自动窗口消融；
5. 信赖域/回退消融；
6. 未见域测试；
7. 至少一个失败案例；
8. 计算成本；
9. 所有配置和种子可复现。

如果自动窗口没有显著优于固定窗口，可将论文结论收缩为：

> 在模型失配下，受约束的任务窗口 ILC 提供更安全的试次间优化；自动窗口检测在特定非几何关键事件中有效。

不得为了维持预定故事而隐藏负结果。
