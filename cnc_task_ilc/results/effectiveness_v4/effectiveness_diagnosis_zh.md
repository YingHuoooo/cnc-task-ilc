# V4 安全组合决策：新机床域确认实验

日期：2026-07-17

## 1. 本轮修改

V4 按 V3 诊断中的最稳妥路线实现：

1. 三个优化窗口中，两个固定为误差峰值安全锚点。
2. 模型只允许决定一个探索窗口，不能完全覆盖强基线。
3. 校准标签不再是单窗口一步收益，而是“三窗口组合执行 4 轮 ILC 后的归一化关键误差 AUC”。
4. 使用多个留一轨迹模型形成集成，并校准风险惩罚与最小替换优势。
5. 内部交叉验证强制探索决策的退化率不超过 10%；若没有可信优势，则退回第三个误差峰值窗口。
6. 全局保护权重保持与误差峰值强基线相同的 `eta=0.30`，避免把权重差异误认为窗口选择收益。

V4 没有继续使用已经反复分析的测试机床种子，而是采用全新的确认种子：`109, 127, 149, 173, 197, 223`。五类轨迹乘六个新机床域形成 30 个确认案例，共运行 10 种方法，即 300 次方法实验。

## 2. 最终结果

V4 成功消除了 V3 的跨轨迹灾难性退化，但没有获得对误差峰值基线的稳定优势，结论仍为 `REVISE`。

相对误差峰值窗口：

- 配对中位 AUC 改善率：**0.00%**；
- 配对平均 AUC 改善率：**-0.15%**；
- 胜出：**3/30**；
- 完全相同：**26/30**；
- 退化：**1/30**；
- 中位全局误差倍率：**1.000**；
- 约束求解成功率：**100%**。

因此，V4 的核心效果是“安全回退基本有效”，不是“性能提高”。预设门槛要求相对最强基线中位改善率至少 10%、胜率至少 60%，V4 分别为 0% 和 10%，没有通过。

## 3. 探索窗口实际发生了什么

内部校准结果为：

| 被留出轨迹族 | 最小替换优势 | 内部回退率 | 内部退化率 | 最终策略 |
|---|---:|---:|---:|---|
| harmonic_loop | 1,000,000 | 100% | 0% | 始终回退 |
| rounded_square | 1,000,000 | 100% | 0% | 始终回退 |
| figure_eight | 1,000,000 | 100% | 0% | 始终回退 |
| s_curve | 1,000,000 | 100% | 0% | 始终回退 |
| ellipse | 1.0 | 83.33% | 0% | 少量探索 |

在新确认域中，前四类轨迹全部退回误差峰值方案；只有 `ellipse` 在四个机床域中采用了探索窗口：

| 机床种子 | 相对误差峰值的 AUC 改善率 |
|---:|---:|
| 109 | +0.20% |
| 127 | +0.09% |
| 173 | +0.23% |
| 197 | **-4.98%** |

前三次收益很小，一次错误探索抵消了全部收益。模型集成的不确定性惩罚在校准中最终都被选择为 0，真正起主要作用的是保守替换阈值，而不是不确定性排序本身。

## 4. 与其他方法的确认集比较

以下结果全部来自同一批新机床域，正值表示 V4 的 AUC 更低。

| 对比方法 | V4 配对中位 AUC 改善率 | V4 胜率 | 结论 |
|---|---:|---:|---|
| 误差峰值窗口 | 0.00% | 10.00% | 基本等价 |
| V2 学习窗口 | +1.79% | 63.33% | 中位数更好，但统计不稳定 |
| V1 固定自动窗口，eta=0.30 | +2.79% | 63.33% | 优于 |
| 固定自动窗口，eta=1.00 | +2.34% | 66.67% | 优于 |
| 全轨迹 ILC | +5.89% | 70.00% | 优于 |
| jerk 窗口 | +13.38% | 83.33% | 明确优于 |
| 曲率窗口 | +15.85% | 90.00% | 明确优于 |
| 随机窗口 | +23.44% | 96.67% | 明确优于 |

V4 相对 V2 的中位改善率为 +1.79%，但 bootstrap 95% 区间为 `[-3.65%, 2.93%]`，单侧 Wilcoxon 检验 `p=0.580`，不能据此宣称稳定优于 V2。

## 5. 学术上最重要的判断

经过 V1 到 V4，继续增加窗口学习模型的收益已经很有限。原因不只是模型能力不足，而是当前评估任务本身高度偏向误差峰值窗口：评估窗口的 85% 分数来自独立校准域的共识误差，测试域误差峰值与这个目标天然高度一致。

这形成了一个接近闭环的定义：

`用误差定义关键区域 -> 再要求新算法超过直接选择误差峰值`

在这种设定下，其他特征最好的结果通常是模仿误差峰值；一旦明显偏离，就容易损失 AUC。V4 的 86.67% 回退率正是数据给出的直接证据。

因此，不建议继续在当前门槛上做 V5 权重或模型调参。更合理的修改是改变论文问题的定义，而不是继续堆叠学习器。

## 6. 推荐的新研究定义

建议保留现有虚拟机床和受约束 ILC 主体，将“关键窗口”改成加工任务事先给定的关键区域：

1. 由轮廓公差、尖角、曲率突变、表面质量要求或进退刀区定义关键区域，而不是由本次误差峰值定义。
2. 算法任务改为在有限修正预算、有限迭代次数下，自动分配学习资源，使这些外部关键区域满足公差。
3. 评价指标使用超差率、最大轮廓误差、达到公差所需迭代数和全局误差代价。
4. 误差峰值窗口仍保留为基线，但不再与评估标签存在近乎同义的关系。
5. 使用新的确认机床域和轨迹族验证跨域泛化。

这会把论文主张从“用复杂模型重新发现误差峰值”转变为“面向外部加工约束的安全学习资源分配”，计算机领域意义和可验证性都会更强。
