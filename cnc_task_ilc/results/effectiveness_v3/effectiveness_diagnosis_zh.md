# V3 仿真收益窗口排序：方法、结果与下一步

日期：2026-07-17

## 1. 本轮做了什么

V2 的学习目标是判断采样点是否属于评估窗口。V3 将其改为更接近最终任务的仿真收益排序：

1. 在五类轨迹的校准机床域上生成候选窗口。
2. 对每个候选窗口真实执行一次受约束 ILC 更新。
3. 用关键误差下降量作为候选窗口奖励，并对全局误差恶化施加惩罚。
4. 使用绝对误差、误差变化率、曲率、jerk、名义控制灵敏度、误差—灵敏度交互项及名义梯度范数预测奖励。
5. 在训练轨迹族内部用嵌套留一轨迹验证选择岭回归强度和误差峰值融合比例。
6. 对被留出的轨迹族和六个测试机床域冻结模型，再选择三个窗口执行 4 轮 ILC。

V3 没有使用被留出轨迹族的标签，也没有更换原来的 30 个测试案例、窗口预算或有效性门槛。正式实验共包含 10 种方法、30 个配对案例，即 300 次方法运行。

## 2. 最终结论

V3 **进一步逼近了误差峰值强基线，但没有形成稳定的总体提升**，有效性结论仍为 `REVISE`。

| 主方法 | 相对误差峰值的配对中位 AUC 改善率 | 胜率 | 全局误差倍率 | 中位窗口 IoU |
|---|---:|---:|---:|---:|
| V1 固定自动窗口 | -4.02% | 26.67% | 0.996 | 0.500 |
| V2 点级校准窗口 | -1.57% | 30.00% | 0.871 | 0.784 |
| V3 仿真收益排序 | **-0.68%** | **33.33%** | **0.871** | 0.500 |

从“距离最强基线还有多远”看，V3 延续了正确方向：差距由 V1 的 4.02% 缩小到 V2 的 1.57%，再缩小到 V3 的 0.68%。但是，V3 仍没有超过误差峰值窗口，也远未满足预设的 `+10%` 改善率和 `60%` 胜率门槛。

## 3. V3 与 V2 的直接比较

在完全相同的 30 个案例中，V3 相对 V2：

- 配对中位 AUC 改善率为 **-0.12%**；
- 胜率为 **46.67%**；
- bootstrap 95% 区间为 **[-3.61%, 0.27%]**；
- 单侧 Wilcoxon 检验 `p=0.841`。

所以不能说 V3 整体优于 V2。更准确的表述是：**V3 在“贴近最强基线”这一指标上更好，但跨轨迹稳定性变差，抵消了收益。**

V3 相对 V1 固定自动窗口的配对中位改善率为 **+3.59%**，胜率 **70%**，bootstrap 95% 区间为 **[0.50%, 7.12%]**。因此，仿真收益排序仍明显优于最早的固定打分方案。

## 4. V3 与各基线的正式结果

| 对比方法 | V3 配对中位 AUC 改善率 | V3 胜率 | 结论 |
|---|---:|---:|---|
| 误差峰值窗口 | **-0.68%** | **33.33%** | 仍略差 |
| 全轨迹 ILC | +2.42% | 86.67% | 优于 |
| jerk 窗口 | +3.13% | 63.33% | 优于但优势有限 |
| 曲率窗口 | +10.86% | 83.33% | 明确优于 |
| 随机窗口 | +17.36% | 83.33% | 明确优于 |

约束求解成功率为 **100%**，相对误差峰值窗口的全局误差倍率为 **0.871**，说明失败并不是约束不可行或全局误差失控造成的。

## 5. 跨轨迹失稳的位置

| 轨迹族 | 相对误差峰值的配对中位 AUC 改善率 | 胜率 |
|---|---:|---:|
| ellipse | -0.68% | 16.67% |
| figure_eight | -0.39% | 33.33% |
| harmonic_loop | **-15.37%** | 16.67% |
| rounded_square | -4.00% | 33.33% |
| s_curve | +0.71% | 66.67% |

主要退化集中在 `harmonic_loop`。校准阶段为被留出的 `harmonic_loop` 和 `rounded_square` 都选择了 `reward_blend=1.0`，即完全相信从其他轨迹学到的奖励预测，舍弃误差峰值安全基线。虽然这种选择在内部轨迹验证上的效用较高，但在新的轨迹几何上发生了明显外推失效。

五个外层模型选择的融合比例为：

| 被留出轨迹族 | 奖励模型融合比例 | 内部交叉验证效用 |
|---|---:|---:|
| harmonic_loop | 1.00 | 0.805 |
| ellipse | 0.50 | 0.750 |
| rounded_square | 1.00 | 0.891 |
| figure_eight | 0.25 | 0.816 |
| s_curve | 0.50 | 0.834 |

这说明内部校准分数无法可靠估计“未见轨迹族”上的风险，当前主要问题已经从特征表达转变为 **跨轨迹分布外泛化**。

## 6. 为什么单窗口奖励仍不够

V3 虽然使用了真实仿真收益，但训练目标与正式指标仍有三个差异：

1. 训练标签来自单个候选窗口，正式执行时一次选择三个窗口，存在窗口之间的互补和竞争。
2. 训练奖励只观察一次 ILC 更新，正式指标是四次更新过程的归一化 AUC。
3. 内部验证只在已见轨迹族之间轮换，无法充分识别新轨迹几何上的高置信错误。

因此，“单窗口的一步收益高”并不保证“三窗口组合的四步 AUC 最优”。这是本轮最有价值的负结果。

## 7. 下一版应怎样改

建议 V4 使用风险受控的组合决策，不再允许奖励模型完全覆盖强基线：

1. **双锚点加单探索窗口**：三个窗口中固定两个来自误差峰值，只允许奖励模型替换或新增一个窗口。
2. **组合级奖励**：训练样本从单窗口改为三个窗口的集合，标签直接使用 4 轮 ILC 的归一化关键误差 AUC。
3. **不确定性回退**：用多个留一轨迹模型形成集成；预测分歧较大时自动退回误差峰值方案。
4. **逐轮重选**：每轮 ILC 后根据剩余误差重新选择探索窗口，而两个安全锚点保持稳定。
5. **新的确认测试集**：由于 V1、V2、V3 已反复查看同一批测试结果，V4 调参完成后应使用新的虚拟机床种子做最终确认，当前 30 例只作为开发集。

V4 的计算机领域表述可以是“带安全回退和不确定性估计的组合式仿真决策”，比继续增加手工轨迹特征更有学术意义。
